# debug_analysis README

Debug files to help with coding the final analysis of opentron outputs. All files are synthetic, generated by `make_example_plates.py`.

## Files

- `example_platemap_plate{1,2}.csv`: identity of each well (index `well`, `A1`..`H12` row-major). Columns: `role`, `mixture_id`, `proxy`, `frac_<solvent>` volume fractions (rounded to 3 dp, so ternaries sum to 0.999), `total_volume_ul`, `standard_conc_mM` (calibration wells only).
- `example_uvvis_plate{1,2}.csv`: matching plate-reader output. Index `wavelength_nm` (200-800 nm, 1 nm step), one absorbance column per well.

## Plate design (per plate, one proxy molecule per well)

| Role | Wells | Content |
|---|---|---|
| `mixture` | 60 | 20 green-solvent mixtures x 3 proxies |
| `pure_solvent` | 18 | 6 pure green solvents x 3 proxies (single-solvent baselines) |
| `dmf_reference` | 3 | pure DMF x 3 proxies (standard) |
| `blank` | 7 | solvent only, no proxy (6 green + DMF) |
| `calibration` | 8 | commercial standard in DMF, 0.125-1.0 mM |

Green solvents: 2-MeTHF, EtOAc, DMC, CPME, MeCN, i-PrOAc. Plate 1 is the initial grid (all 15 equal-part binaries + 5 equal-part ternaries). Plate 2 mimics a Bayesian-optimisation round 2 (20 two- or three-component mixtures in 5 % steps).

Spectra: each proxy has one Gaussian band (A 275 nm, B 320 nm, C 410 nm; standard 350 nm) scaled by a fake "dissolved fraction" that rewards balanced mixtures, on a UV-rising baseline with noise.

## Assumptions (placeholders, change when the real system is defined)

- The three proxies are generic `proxy_A`, `proxy_B`, `proxy_C` with made-up band positions (275, 320, 410 nm); swap in the real molecules and their λmax when known.
- Volume fractions are rounded to 3 decimal places, so equal-part ternaries sum to 0.999 rather than 1.
- The calibration standard is dissolved in DMF; the proposal does not specify its solvent.
